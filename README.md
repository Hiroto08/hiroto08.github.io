# hiroto08.github.io

開発者サイト。ストア掲載の「開発者ウェブサイト」（App Store のマーケティングURL、
Google Play のウェブサイト欄）に `https://hiroto08.github.io/` を登録する。

`app-ads.txt` はドメイン直下に置く必要があるため、このユーザーサイト用リポジトリで配信している。
AdMob はストア掲載のウェブサイト欄のドメインを見て、`/app-ads.txt` を確認する。

アプリを追加したら `index.html` の一覧に足す。広告ネットワークを増やしたら `app-ads.txt` に1行足す。
